# Notebooks Directory

This folder contains the core experimentation and setup notebooks used in the NLP9 emotion classification project. The primary objective is to train and evaluate multiple models, particularly focusing on BERT, using emotion-labeled text data from various sources. The models aim to classify emotional tone in Dutch television show transcripts and other emotion datasets.

## Folder Structure

- `bert_iteration3.ipynb`: This notebook documents the third iteration of training a BERT-based Transformer for emotion classification.

- `datastores_test.ipynb`: This notebook facilitates interaction with Azure Machine Learning services for data handling.
